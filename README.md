## Overview

GitHub in Slack and Teams makes it easier to collaborate and build software. 
This new integration provides seamless integration between your GitHub projects and your preferred communication platforms, Slack and Teams.  You can now discuss bugs, create issues, implement changes, and even open pull requests, all directly within the context of your Slack or Teams conversation. This streamlined workflow helps teams collaborate more effectively and reduces the need to jump between different applications. For instance, imagine you're on a call with your team about a bug you found in the website's checkout process. You can quickly create a GitHub issue with a clear description of the issue, attach screenshots, and link to relevant code within your Slack channel. 

It allows you to: 
* Build and review code right in your conversation
* Create issues and pull requests from within the context of a Slack or Teams message
* Directly collaborate on code and projects without switching platforms
